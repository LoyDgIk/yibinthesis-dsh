# 宜宾学院毕业材料规范

本技能汇总**校发规范与学部细则**中的硬性要求，供写作前自查与交付前核对。
全部条目均标注来源文件，便于回查原文。

> **本技能是规范摘录，不是学校正式文件。** 新通知、学部补充规定与毕业设计管理系统
> 内的最新要求**优先于**本文；本工具为**非官方**实现，最终以学校与指导教师意见为准。

## 首要判断：确认适用哪一套要求

**两套要求并存且数值不同**，用错会导致返工。先确认培养类型：

| | 普通本科 | 高等学历继续教育 |
| --- | --- | --- |
| 版式年份 | 2024 | 2025 |
| 参考文献 | **≥ 20 篇**，近五年 ≥ 50% | **≥ 15 篇**，以近十年为主 |
| 封面字段 | 含校外指导教师 | 无校外导师栏 |
| 依据 | 《撰写规范》（2022 修订）+ 2024 模板 | 2025 版模板 |

其余要求（结构、字体、编号、图表、抽检要素）两者一致。

## 结构要求（两类通用）

毕业论文（设计）由以下部分依次构成，**装订顺序与此相同**：

```
封面 → 中文摘要及关键词 → 英文摘要及关键词 → 目录
     → 正文（绪论 / 主体 / 结论）→ 致谢 → 参考文献 → 附录
```

| 部分 | 硬性要求 |
| --- | --- |
| 题目 | 中文 ≤ 20 字；英文 ≤ 10 个实词；必要时可加副标题 |
| 中文摘要 | 约 250 字；**不得使用公式、图表，不标注引用文献编号** |
| 英文摘要 | 内容与中文摘要对应 |
| 关键词 | **3–5 个**，按外延层次排列（外延大的在前） |
| 目录 | 涵盖一、二、三级标题；独立成页；标题须与正文一致 |
| 绪论 | **≥ 3000 字**；含目的/背景/意义、国内外研究状况、设计与研究方法、研究内容 |
| 主体 | 结构与结论合计 **≥ 8000 字** |
| 结论 | 单独一章排列，**不加章号** |
| 致谢 | 独立成页 |
| 参考文献 | 见上表两类差异；同一文献多处引用只出现一次，序号按**首次引用**位置 |
| 附录 | 篇幅**不宜超过正文** |

各标题**一般 ≤ 15 字，不使用标点符号**；尽量不用英文缩写，必须使用时须为本行业通用缩写。
正文各层次标题**不得置于页面最后一行**（避免孤行）。

## 标题层次与编号

学科决定编号体系，**两者不可混用**：

| 层次 | 人文社科类 | 理工农医类 |
| --- | --- | --- |
| 一级 | 一、二、三、 | 1、2、3 |
| 二级 | （一）（二）（三） | 1.1、1.2 |
| 三级 | 1. 2. 3. | 1.1.1、1.1.2 |
| 四级 | （1）（2）（3） | 1.1.1.1 |

理工农医类的分级阿拉伯数字**一般不超过四级**；两级之间用下角圆点隔开，每级末尾不加标点。

## 页式与字体（照抄即可照做的规格）

**页面**：A4、横排、不分栏、单面打印、左侧装订。

| 项 | 值 |
| --- | --- |
| 页边距 | 上 2.5 cm，下 2.5 cm，左 3.0 cm，右 2.5 cm |
| 页眉 / 页脚 | 各 1.5 cm |
| 行距 | 1.5 倍 |
| 摘要页码 | 小五号希腊数字 Ⅰ、Ⅱ、Ⅲ…，页脚居中 |
| 正文页码 | 小五号阿拉伯数字，页脚居中 |
| 正文页眉 | 本人毕业设计（论文）题目 |

**文字规格**（每部分均**另起一页**）：

| 部分 | 规格 |
| --- | --- |
| 封面 · 中文题目 | 小二号黑体，加粗，居中 |
| 封面 · 其余字段 | 三号宋体，加粗，居中 |
| 摘要标题 / 英文摘要标题 | 小三号黑体加粗 / 小三号 Times New Roman 加粗 |
| 摘要正文 / 英文摘要正文 | 小四号宋体 / 小四号 Times New Roman |
| 关键词标签 / 内容 | 小四号黑体 / 小四号宋体（**分号分隔，末尾不加标点**） |
| 目录标题 / 内容 | 小三号黑体 / 小四号宋体 |
| 一级标题 | 三号黑体，加粗 |
| 二级标题 | 小三号楷体，加粗 |
| 三级、四级标题 | 四号宋体，加粗 |
| 正文 | 首行空两格，小四号宋体 |
| 正文中的注释 | 五号宋体 |
| 致谢标题 / 内容 | 小三号黑体 / 小四号宋体 |
| 参考文献标题 / 内容 | 小三号黑体 / **五号宋体** |
| 引用标示 | 置于所引内容最末句的**右上角**，小五号 |

## 图表、公式与注释

| 对象 | 编号 | 题注位置 |
| --- | --- | --- |
| 图 | 以章为单位连续编号 | 图序与图题在**图下方居中** |
| 表 | 以章为单位连续编号 | 表序与表题在**表上方正中**，表序后空一格写表题 |
| 公式 | 以章为单位连续编号（如 3.1、4.1） | 居中书写，编号用**圆括号**置于右边行末，之间不加虚线 |

- 表格**允许下页接写**：表题可省略，表头须重复，并在右上方标注「续表××」。
- 表格风格：人文社科类用 表1、表2…；理工农医类一般用**三线表**，编号 表2.1、表3.1…
- 注释采用**顺序编码制**，用带圆圈序号（①②③…）置于标注处右上角，条目集中列于**参考文献之前**。

## 参考文献著录（GB/T 7714-2015）

**顺序编码制**：按正文出现先后用**方括号**阿拉伯数字编号（**不用圆括号**）。
序号**顶格**书写、不加括号与标点，其后空一格写作者名；换行时与作者名首字对齐。
同一文献反复引用**使用同一序号**。

常见类型格式：

| 类型 | 格式 |
| --- | --- |
| 专著 / 论文集 / 学位论文 / 报告 | `[序号]主要责任者.文献题名[文献类型标志].出版地:出版者,出版年.` |
| 期刊 | `[序号]主要责任者.文献题名[J].刊名,年,卷(期):起止页码.` |
| 报纸 | `[序号]主要责任者.文献题名[N].报纸题名,出版日期(版次).` |
| 标准 | `[序号]标准编号,标准名称[S].出版地:出版者,出版年.` |
| 析出文献 | `[序号]析出文献责任者.析出文献题名[C]//原文献主要责任者.原文献题名.出版地:出版者,出版年.` |
| 电子文献 | `[序号]主要责任者.题名[EB/OL].(更新日期)[引用日期].访问路径.` |

文献类型标志：专著 `[M]`、会议论文集 `[C]`、报纸 `[N]`、期刊 `[J]`、学位论文 `[D]`、
报告 `[R]`、标准 `[S]`、专利 `[P]`、析出文献 `[A]`；电子文献类型 `[DB]`/`[CP]`/`[EB]`；
载体类型 `[OL]`/`[CD]`/`[MT]`/`[DK]`。

其他规定：

- 作者为多人时**只列 3 名**，其后加「等」，姓名间用逗号。
- 外文姓名：**名的缩写置前，姓置后**；题名首字母大写；刊名可用全称或 ISO 4 缩写。
- **网上参考文献不计入**规定的文献篇数，但须注明准确网页地址。
- 学术会议未出版论文集时，省略「出版者」「出版年」；会议地址与出版地相同则省略出版地。
- 学术刊物无卷号时略去该项，直接写「年,(期)」。

## 学术诚信红线

以下行为按学校与教育部规定属**学术不端**，可导致开除学籍：

- 抄袭、篡改、伪造研究成果；**代写论文、买卖论文**（《普通高等学校学生管理规定》教育部令第 41 号第五十二条）。
- 引用他人成果**必须注明出处**，不得与本人分析混淆；将其他领域理论引入本研究领域须说明出处并论述可行性。

过程性要求（学部细则）：学生应**每周 1–2 次**向指导教师汇报进展，
并在毕业设计管理系统中如实填写每次指导情况（时间、修改意见、指定参考资料、联系方式）。
指导教师**书面修改意见的论文原稿不少于三稿**，作为指导过程记录。

## 过程节点与选题约束（学部细则）

```
选题 → 开题（含开题答辩）→ 中期检查 → 答辩 → 修改定稿 → 归档
```

- 选题须**一人一题**；多人共同课题须明确各自独立完成的子任务。
- 学生**自拟课题控制在总数 5% 以内**；以实践性工作为基础的论文占比 ≥ 50%。
- 题目由指导教师申报、教研室主任审定、学部主管教学副部长批准后公布，**不得随意更改**。
- **文献综述不得作为毕业论文（设计）选题。**
- 开题报告的**主要参考文献不低于 15 篇**。
- 开题报告、中期汇报检查表均须上传毕业设计管理系统并经指导教师签字。

## 文献综述要求

| 项 | 要求 |
| --- | --- |
| 字数 | **≥ 2500 字**（美术、音乐、体育各专业 ≥ 1000 字） |
| 中文摘要 | **≤ 100 汉字** |
| 关键词 | 3–5 个 |
| 参考文献 | **≥ 15 项**，尽量使用**近三年**资料 |
| 格式 | 打印格式**参照毕业论文（设计）打印格式** |

结构：题目、著者、摘要、关键词、正文（导言 / 主体 / 总结）、参考文献。

主体须包含三方面，缺一即不完整：

1. **历史发展** —— 按时间顺序说明课题的提出与各阶段发展状况；
2. **现状分析** —— 国内外研究现状与各派观点；
3. **趋向预测** —— 在纵横对比中提出问题、给出展望。

须体现「**综**」与「**述**」：不仅要归纳整理，还要做比较、分析与系统论述，
最终**阐明本课题选题的依据与意义**。不得为凑篇幅堆砌不相关文献。

## 四川省抽检评议要素

省抽检按 100 分制评议，权重如下（据《四川省本科毕业论文（设计）抽检评议要素》）：

| 一级指标（分值） | 二级指标（分值） | 评议要点 |
| --- | --- | --- |
| 选题意义（10） | 选题目的（5） | 符合专业培养目标，体现综合训练基本要求 |
| | 研究意义（5） | 面向学术问题或行业实际问题，有理论意义或实用价值 |
| 写作安排（15） | 文献调研（10） | 综合分析国内外文献，追踪研究现状或行业动态，**能支撑选题** |
| | 进度安排（5） | 时间安排合理，工作量饱满，形式符合专业特点 |
| 逻辑构建（20） | 层次体系（10） | 体系完整，层次分明，重点突出 |
| | 逻辑结构（10） | 论点鲜明，论据确凿，论证充分 |
| 专业能力（35） | 综合应用知识（10） | 基础理论与专业知识合理应用于研究过程 |
| | 分析解决问题（15） | 研究方法合理，论证严谨，**数据记录规范** |
| | 创新能力（10） | 阐明新观点，或创新性应用经典理论，或阐释实践指导意义 |
| 学术规范（20） | 行文规范（10） | 文字表达、书写格式、图表、公式符号、缩略词符合通行规范 |
| | 引用规范（10） | 资料引证与参考文献符合学术规范与知识产权规定 |

**权重提示**：专业能力合计 **35 分**为最高权重，其次学术规范 20 分。
即「方法合理 + 数据规范 + 引用合规」比选题包装更影响评议结果。

## 自查清单（交付前逐条核对）

**内容**

- [ ] 中文题目 ≤ 20 字；英文题目 ≤ 10 实词
- [ ] 中文摘要约 250 字，**无公式/图表/引用编号**
- [ ] 关键词 3–5 个，按外延由大到小
- [ ] 绪论 ≥ 3000 字；主体 + 结论 ≥ 8000 字
- [ ] 结论单独成章且**不加章号**
- [ ] 各标题 ≤ 15 字、无标点、无孤行

**参考文献**

- [ ] 篇数达标（普通本科 ≥ 20；继续教育 ≥ 15）
- [ ] 时效达标（普通本科近五年 ≥ 50%；继续教育以近 10 年为主）
- [ ] 顺序编码制、方括号、按首次引用排序、序号顶格
- [ ] 同一文献只出现一次
- [ ] 网上文献另行注明网址且不计入篇数

**版式**

- [ ] 页边距 上/下 2.5、左 3.0、右 2.5 cm；页眉页脚 1.5 cm；行距 1.5
- [ ] 摘要页码用 Ⅰ、Ⅱ、Ⅲ；正文页码用阿拉伯数字
- [ ] 正文页眉为论文题目
- [ ] 各级标题字体字号符合规格表
- [ ] 图题在图下、表题在表上，均以章为单位连续编号
- [ ] 公式编号用圆括号、右端对齐
- [ ] 参考文献内容为**五号宋体**
- [ ] 每部分另起一页；装订顺序正确
